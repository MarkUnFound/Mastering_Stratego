11. IMPERFECT INFORMATION AND SIDE-MODEL CONSIDERATIONS
--------------------------------------------------------------------------------

  Both architectures operate as SIDE models — they do not directly
  interact with the game engine but instead provide action rankings
  to the game controller. This is critical because Stratego is a
  game of imperfect information where:

  1. Hidden opponent pieces create irreducible epistemic uncertainty
  2. The model must make decisions with incomplete state observation
  3. Catastrophic decisions can arise from incorrect hidden-state beliefs

  LSTM Approach:
    - Processes board states sequentially through recurrent connections
    - Hidden state carries forward temporal information
    - Limitation: sequential bias — recent observations dominate, making
      it hard to attend to board-wide patterns or long-range dependencies
    - Limitation: hidden state capacity bottleneck constrains the complexity
      of belief representations for unknown pieces

  AAREN (Rainbow) Approach:
    - Uses attention over the full visible board state
    - Can attend to arbitrary spatial relationships (global attention)
    - Distributional Q-learning (C51) models VALUE UNCERTAINTY explicitly,
      which is theoretically better suited for imperfect-info games
    - Prioritized experience replay focuses on surprising/important transitions
    - Limitation: ~11x larger model size increases inference latency
    - Limitation: Requires significantly more training data to converge

13. COST-BENEFIT ANALYSIS: IS THE HEAVIER ARCHITECTURE WORTH IT?
--------------------------------------------------------------------------------

  Arguments FOR the Rainbow DQN + AAREN transition:

    1. HIGHER WIN RATE at lower episode count: 49.24% vs 24.97%
       at 8,000 vs 15,302 episodes
    2. DRAMATICALLY LOWER DRAW RATE: 6.15% vs 50.04%
       indicating the model makes decisive decisions rather than timing out
    3. DISTRIBUTIONAL Q-LEARNING (C51) provides uncertainty-aware value
       estimation, theoretically better for imperfect-information games
    4. ATTENTION MECHANISM allows global board reasoning vs LSTM's
       sequential/local processing
    5. The LSTM architecture PLATEAUED at ~22% after 37k episodes,
       suggesting a fundamental ceiling rather than insufficient training

  Arguments AGAINST the transition:

    1. ~11x LARGER MODEL SIZE (433 MB vs 39 MB per checkpoint)
    2. HIGHER PER-STEP COMPUTE COST due to attention and distributional heads
    3. ONLY 8k EPISODES trained — too early to confirm the win rate trend
       will hold beyond the LSTM's plateau region
    4. SIDE-MODEL ARCHITECTURE means the DQN is advisory only —
       a more sophisticated embedded approach might be needed regardless
    5. In imperfect-information settings, model improvements may yield
       diminishing returns if the OBSERVATION FUNCTION is the bottleneck

  VERDICT:
    The data at this stage is CAUTIOUSLY SUPPORTIVE of the architectural
    transition. The Rainbow+AAREN system achieves a higher win rate and
    dramatically fewer timeouts despite being at a much earlier training
    stage. The key risk is whether the win rate will plateau at a similarly
    low level as the LSTM once the model encounters the same diversity of
    league opponents at scale. The 11x model size increase is non-trivial
    but acceptable for a research system (not deployment-constrained).

    Critical next step: continue Rainbow training to at least 15k–20k
    episodes to directly compare against the LSTM's plateau region.
